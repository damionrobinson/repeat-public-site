Opening Repeat

The beta isn't signed with an Apple Developer ID yet, so macOS blocks it by default the first time — this is normal, and only takes a minute to get past.

macOS will say the app "can't be opened" or is from an "unidentified developer". That's expected for an unsigned beta, not a sign anything's wrong with the download.

1. Unzip and move it to Applications

Double-click the downloaded .zip, then drag Repeat.app into your Applications folder.

2. Open it the first time

Double-clicking it will show a warning and refuse to open — that's expected. Instead:

  1. Open System Settings → Privacy & Security.
  2. Scroll down to the Security section. You'll see a line about Repeat being blocked, with an Open Anyway button next to it. Click it.
  3. Confirm in the dialog that appears.

(On older macOS versions you could right-click the app and choose Open instead — macOS 15 removed that shortcut for unsigned apps, so Open Anyway in System Settings is the one reliable path now.)

You only need to do this once per download. If you download a newer build later, you'll need to repeat this step for that one too — each build is its own unsigned app as far as macOS is concerned.

3. Grant permissions

Repeat will ask for two permissions the first time it needs them:

  • Microphone — to hear you while you hold the dictation shortcut.
  • Accessibility — to paste your words into other apps, and to read text you select for proofreading.

Same as step 2: a new build means regranting these too, since macOS ties permissions to the exact unsigned app it saw before.

4. Updates

There's no auto-update for the beta yet — check back on the site for a newer download, and repeat steps 2-3 for it.
